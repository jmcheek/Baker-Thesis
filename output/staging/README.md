# Statute results

- `2025/<State>/`: saved statute text, source metadata, and review notes.
- `retrieved.csv`: saved files and retrieval review notes.
- `unresolved.csv`: bills still needing resolution.
- `reports/`: historical retrieval reports.
- `cache/`: cached API responses (ignored by Git).
- `documents/`: source documents used by retrieval (ignored by Git).

Saved results describe prior runs. Existing statute files retain their original
source and processing metadata; review notes should be checked before analysis.
The importer preserves existing statute files.
