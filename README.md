# Baker-Thesis

Research on themes in enacted U.S. state AI legislation.

## Research report

[Preliminary theme analysis](docs/theme-research.md) covers word frequencies,
recurring themes, state comparisons, and three rounds of codebook review.
The report distinguishes lexical cues from provisional thematic judgments.

## Data

- [Statute texts](output/staging/2025): statute files organized by state.
- [Retrieved bills](output/staging/retrieved.csv): saved files and review notes.
- [Unresolved bills](output/staging/unresolved.csv): bills still needing resolution.
- `data/ncsl/`: NCSL source material, bill list, and reviewed bill selections.

Existing statute files retain their source metadata and review notes. The saved
results describe earlier retrieval runs; they are not regenerated automatically.
